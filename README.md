# F1 Race Intelligence

An end-to-end Formula 1 race prediction and strategy platform.

## Project Overview

F1 Race Intelligence replays historical Formula 1 races lap by lap
and generates machine-learning predictions and race strategy insights.

## Technology Stack

- Python
- FastF1
- Pandas and NumPy
- Scikit-learn and LightGBM
- PostgreSQL
- FastAPI
- Redis
- React and TypeScript
- Docker

## Project Status

Currently in development.
